## 3. Broken Backlink Swap Targets

### How to find:
1. Google: `site:competitor.com` then check their 404 pages via Ahrefs/Ubersuggest free tier
2. Target sites: web design agency directories, AU tech blogs, "best web designers" lists
3. Find pages that link to 404'd competitor pages
4. Email the linking site: "Hey, I noticed your link to [DEAD URL] is broken. We cover the same topic at [YOUR URL] — happy to let you know if you'd like to update it."

### Competitor domains to check for broken backlinks:
- webdesignmelbourne.com.au (often has stale links pointing to it)
- sydneywebdesign.com.au
- Other local AU web agencies

## 6. Analytics Setup Checklist

### Google Search Console (most important — do first)
1. Go to **search.google.com/search-console** → Add property → Domain
2. Google gives you a TXT record → add it in your domain registrar's DNS
3. OR: add the `<meta name="google-site-verification">` tag in `index.html` (placeholder already there)
4. After verify: Sitemaps → submit these URLs:
   - `https://buildfirstsite.com/sitemap-index.xml`
   - `https://buildfirstsite.com/sitemap.xml`
   - `https://buildfirstsite.com/sitemap-city-pages.xml`
   - `https://buildfirstsite.com/sitemap-service-pages.xml`
   - `https://buildfirstsite.com/sitemap-images.xml`
5. URL Inspection → `https://buildfirstsite.com/` → Request indexing
6. Do the same for all 5 city pages + 3 service pages

### Google Analytics 4 (do second)
1. **analytics.google.com** → Create property → Get Measurement ID (`G-XXXXXXXXXX`)
2. Paste into `index.html` GA4 block (placeholder already there), uncomment, redeploy
3. In GA4: Admin → Events → Mark **"generate_lead"** as a Key Event (already fired in contact form code)
4. Check: Realtime → open your site → should see 1 active user

### Bing Webmaster Tools (5 min — free traffic)
1. **bing.com/webmasters** → "Import from Google Search Console" (one click)
2. Done. Bing also powers ChatGPT/Copilot web search — worth the 5 minutes.

### Google Business Profile (local SEO + Maps)
1. **business.google.com** → Service-area business (no storefront needed)
2. Name: "Build First Site"
3. Category: "Web designer" primary + "Software company" secondary
4. Service areas: Sydney, Melbourne, Denver, Phoenix, Nashville
5. Add all 4 services: Web Design, Web Development, E-Commerce Development, AI Web Applications
6. Upload portfolio screenshots (HS Race Gear, Harbour Plumbing, Marlow & Vine screenshots)
7. Get first 3+ reviews from clients → star rating appears in search
