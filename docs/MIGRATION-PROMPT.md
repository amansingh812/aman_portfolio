## THE PROMPT — copy from here

> ### Context
>
> You are migrating legacy static HTML pages in `public/<slug>/index.html` to
> Next.js routes so they use the Agon design system and the real site chrome.
>
> **Read these first, in order:**
> 1. `CLAUDE.md` — business context, honesty constraints (§1), stack (§2)
> 2. `content/pricing.js` — the ONLY source of truth for prices
> 3. `content/landing-pages.js` — the data model and migration steps
> 4. `components/landing/LandingPage.js` — the shared renderer
> 5. `app/ai-web-development/page.js` — a completed migration, copy this pattern
>
> ### Why this migration exists
>
> Static pages cannot import React, so each one hardcodes its own mini header
> and footer, loads Tailwind from a CDN, and carries a **copy** of the price
> table. That is why the theme drifts and prices go stale in 18 places.
>
> Two real SEO gains (not "Next ranks better" — it doesn't):
> - **Kills `cdn.tailwindcss.com`**, which compiles CSS in the browser at
>   runtime. Render-blocking, hurts LCP, and Core Web Vitals is a ranking
>   factor. 18 pages currently load it.
> - **Internal links go from 11 to 18 per page** — static pages have a fake
>   mini-footer; Next routes get the real Footer.
>
> ### The three steps — all three, every time
>
> 1. Add an entry to `content/landing-pages.js`
> 2. Create `app/<slug>/page.js` (6 lines — copy `app/ai-web-development/page.js`)
> 3. **DELETE `public/<slug>/index.html`**
>
> **Step 3 is not cleanup — it is the switch.** `next.config.mjs` uses
> `beforeFiles` rewrites generated by scanning `public/` for `index.html`.
> `beforeFiles` runs before the app router, so while the static file exists it
> shadows your new route and you will never see it. The rewrite list is built
> when `next.config.mjs` is evaluated, so **restart `npm run dev`** after
> deleting or you will still see the old page.
>
> ### Non-negotiable rules
>
> - **URL must not change.** Same slug in, same slug out. That is what
>   preserves rankings. No redirects needed if the URL is identical.
> - **Never hardcode a price.** Use `priceTiers: ['starter','business']` and
>   let the renderer pull from `content/pricing.js`.
> - **Never hardcode px font sizes or hex colours.** Use Agon utility classes:
>   `text-heading-1..6`, `text-body-lead-large`, `text-body-text`,
>   `text-body-small`, `color-gray-900/600/500`, `color-green-900`, `tag-1`,
>   `bg-6`, `btn-black`, `btn-default`, `section-box`.
> - **Only `/web-design-melbourne/` may emit `LocalBusiness` /
>   `ProfessionalService`.** It is the one verified GBP location. Every other
>   page emits `Service` with `provider: {"@id": ".../#localbusiness"}`.
>   Multiple business entities fragment the entity Google builds of us.
> - **Honesty constraints (`CLAUDE.md` §1) apply to every word.** No invented
>   testimonials, metrics or client names. Real clients only: hsracegear.com ·
>   mobilearmour.com.au · autozenlyai.com · planet.ltfinance.com. Concept
>   builds must be labelled as concept builds.
> - **Australian English** — optimise, colour, organisation.
>
> ### Content quality bar
>
> Do not port the old copy across. Rewrite it against current context:
> parity pricing ($800 / $1,900 / $3,500 / $4,500 / from $5,000 / $250 per
> month), Melbourne-based, code ownership as the sharpest wedge.
>
> Every page needs:
> - **900+ words minimum.** Under 700 is a thin-content error.
> - `metaTitle` ≤ 60 chars, `metaDescription` 120–158 chars
> - One H1, keyword-relevant H2s
> - At least one honest "when we are the wrong choice" section — it is the
>   differentiator and it converts
> - 3–5 `faq` blocks (these auto-generate FAQPage schema)
> - ≥ 3 internal links via the `related` array
> - Business outcome before technical detail in every section
>
> ### After each batch
>
> ```bash
> python3 scripts/seo-audit.py     # must show 0 new errors
> npm run dev                      # restart, then check each migrated URL
> ```
>
> Confirm for every page: real navbar with dropdowns, real footer, correct
> price, valid JSON-LD, canonical present, URL unchanged.
>
> ### Batch 1 — do only this, then stop and report
>
> Migrate these two. Both are currently thin-content errors, so they need a
> real rewrite, not a port:
>
> - `ecommerce-development` (388 words → 1,200+). Target
>   "ecommerce development australia". Angle: Stripe checkout with real
>   inventory, no per-sale platform commission, you own the store. Price tiers:
>   `['ecommerce','custom-software']`.
> - `nextjs-development` (379 words → 1,200+). Target "nextjs development
>   australia". Angle: why the stack matters to a business — speed, SEO,
>   no plugin tax. Business outcome before framework names. Price tiers:
>   `['business','unlimited','custom-software']`.
>
> Do not touch any other page. Report back when both pass the audit.
